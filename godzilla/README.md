# Godzilla ASCII — Atomic Breath

Một con kaiju 3D vẽ hoàn toàn bằng ký tự ASCII (cùng chất liệu với cây thông Noel). Tất cả nằm trong một file `index.html`.

## Diễn biến (~14 giây rồi giữ cảnh tuyết rơi)

| Thời điểm | Chuyện gì xảy ra |
|---|---|
| 0–1,2s | Màn hình tối om, chỉ có tàn lửa bay |
| 1,2–8,4s | Ánh xanh tích từ chóp đuôi chạy dọc sống lưng lên đầu, gai lưng sáng dần, màn hình sáng dần |
| 8,4s | Năng lượng lên tới đầu: lóe sáng, Godzilla hiện ra hoàn toàn, ngẩng đầu |
| 9,6–13,4s | Phóng hơi thở nguyên tử lên trời, rung màn hình, vòng sáng nổ trên mây |
| từ 11,2s | Mưa tuyết dày dần, tuyết đọng lên lưng và mặt đất, gai lưng thở sáng nhẹ |

## Chạy

- **Windows / Mac:** mở `index.html` bằng Chrome, Edge hoặc Firefox.
- **iPhone:** mở bằng Safari; "Thêm vào MH chính" để chạy toàn màn hình.

## Điều khiển

- Kéo ngang để xoay góc nhìn (thả ra sẽ tự trở về góc sau lưng)
- `replay` hoặc phím `R`: chạy lại từ đầu
- `code` hoặc phím `C`: ẩn/hiện khung code đang chạy (khung tô sáng đúng đoạn code của cảnh đang diễn ra)
