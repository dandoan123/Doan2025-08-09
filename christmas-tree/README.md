# Cây thông ASCII

Cây thông Noel 3D vẽ bằng ký tự ASCII. Cây tự dựng từ gốc lên ngọn, rồi xoay tròn với đèn nháy, ngôi sao lóe sáng, hộp quà và tuyết rơi. Tất cả nằm trong một file duy nhất: `index.html`.

## Chạy

- **Windows / Mac:** mở `index.html` bằng Chrome, Edge hoặc Firefox (nhấp đúp vào file là được).
- **iPhone:** mở file trong Safari (gửi file qua AirDrop hoặc lưu vào ứng dụng Tệp rồi mở). Bấm Chia sẻ → "Thêm vào MH chính" để chạy toàn màn hình như một app.

Không cần cài gì thêm. Lúc không có mạng, trang dùng font monospace có sẵn trong máy.

## Điều khiển

| Thao tác | Tác dụng |
|---|---|
| Kéo ngang trên cây | Xoay cây (có quán tính) |
| `replay` / phím `R` | Dựng lại cây từ đầu |
| `message` | Đổi dòng chữ dưới gốc cây (tiếng Việt có dấu cũng được) |
| `code` / phím `C` | Ẩn/hiện khung code đang chạy |
| Phím ← → | Đẩy cho cây quay nhanh hơn |
